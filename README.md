# 🌿 Kindora – Community Event Platform

**Kindora** is a community-focused platform designed to bring people together through meaningful events and social activities. It helps users discover upcoming events, explore activities by city, and participate in initiatives that create a positive impact on society.

## 🌐 Live Links

| Resource | URL |
|---|---|
| **Live Website** | https://kindora-green.vercel.app |
| **Backend API** | https://kindora-server-peach.vercel.app/ |

## ✨ Key Features

- **Event Discovery:** Explore various community events and social activities.
- **City-Based Search:** Find events by searching for your preferred city.
- **Upcoming Events:** Browse upcoming events and stay informed about community activities.
- **Event Details:** View event descriptions, dates, locations, and other relevant information.
- **Secure Authentication:** User authentication with Better Auth.
- **Responsive Interface:** Smooth browsing experience on desktop, tablet, and mobile devices.
- **Community Initiatives:** Discover activities related to social work, environmental protection, healthcare, and education.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/meherinamukta03/kindora.git
```

**2. Navigate to the project directory**

```bash
cd kindora
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:3000
```
